FREE HOSTING:
Recommended: GitHub Pages.
1. Create a free GitHub account at github.com.
2. Create a new PUBLIC repository named: hemant-tiwari-website
3. Upload index.html and the entire images folder.
4. Open Settings -> Pages.
5. Under "Build and deployment", choose "Deploy from a branch".
6. Select branch "main" and folder "/ (root)", then Save.
7. After deployment, GitHub will show your free website address.

IMPORTANT:
- This site is a static website, so hosting can be free.
- The contact form opens the visitor's email app using mailto; no paid form service is required.
- You can later connect a custom domain if you want.
